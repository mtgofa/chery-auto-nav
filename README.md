# CheryNav — Navigation & Map Bridge (Bluetooth)

مشروع لربط شاشة سيارة شيري (**Windows CE 6.0 / ARMV4I**) بهاتف أندرويد **عبر البلوتوث فقط (Bluetooth SPP)**،
لعرض التوجيه خطوة بخطوة (Turn-by-Turn)، خط المسار على الخريطة، وعداد سرعة ذكي مع ETA — بتحكّم باللمس من الشاشة.

> **التحميل المباشر (آخر بناء من الـ CI):**
> - شاشة السيارة (WinCE): https://github.com/mtgofa/chery-auto-nav/releases/download/latest/CheryNav.exe
> - تطبيق الموبايل (Android): https://github.com/mtgofa/chery-auto-nav/releases/download/latest/app-debug.apk

## ⚡ فكرة العمل (How It Works) — بلوتوث ومزامنة مربعات الخريطة

1. **الاقتران (Pairing):** الهاتف يفتح سيرفر **Bluetooth SPP** باسم `CheryNavBridge` (UUID القياسي
   `00001101-...`). شاشة السيارة فيها موديول بلوتوث بيظهر كمنفذ سيريال داخلي (مثلاً `COM4:`)،
   وتطبيق الشاشة يتصل بالهاتف عبر المنفذ ده.
2. **البروتوكول (Chery Binary Protocol):** حزم ثنائية خفيفة جداً بـ Magic `0x43485259` ('CHRY')
   يبثّها الهاتف:
   - **تيليمتري (10 Hz):** السرعة، الاتجاه (heading)، إحداثيات GPS.
   - **توجيه + مسار + Heartbeat (2 Hz):** نوع المنعطف، المسافة للّفة، الوقت/المسافة المتبقية،
     اسم الشارع، **خط المسار كـ Vector Polyline**، وحالة البطارية.
   - **مربعات الخريطة الديناميكية (Dynamic Tile Syncing - 0x0007):** مربعات الخريطة الحقيقية
     (Slippy Map Tiles 256x256 بصيغة JPEG خفيفة ~10-15KB) تُرسل في الخلفية بمعدل 1 مربع كل ثانية ونصف.
   - **إقرار الاستلام (Tile ACK - 0x0012):** عند حفظ الشاشة للمربع على الـ SD Card، ترسل فوراً إقراراً للهاتف
     فيسجلها الهاتف ولا يعيد إرسال هذا المربع مجدداً إطلاقاً!
3. **عرض الخريطة على الشاشة:**
   - شاشة السيارة تحفظ المربعات المستلمة على كارت الميموري (`\Storage Card\CheryNav\tiles\`).
   - تقوم بفك ضغط صور الـ JPEG داخلياً بسرعة فائقة باستخدام محرك `stb_image` وتجميعها ورسمها خلفية للشاشة.
   - ترسم فوقها خط المسار (Cyan Polyline) وسهم السيارة وعداد السرعة.
   - إذا لم تتوفر مربعات لمنطقة معينة بعد، تنتقل بسلاسة للشبكة المتجهية السريعة (Vector Grid).
   - **ميزة التحميل المسبق بالكامل (Offline Pre-load):** يمكنك وضع مجلد صور المربعات `.jpg` مباشرة في
     `\Storage Card\CheryNav\tiles\` وستتعرف الشاشة عليها فوراً وتعمل بدون أي استهلاك لباندويث البلوتوث!
4. **عرض الخريطة على الموبايل (Live OsmMapView):**
   - واجهة الهاتف أصبحت تحتوي على خريطة حية تفاعلية مدمجة تعرض موقع السيارة الآني ومسار الرحلة
     وحالة مزامنة المربعات (كم مربع تم حفظه على الشاشة، وكم مربع قيد المزامنة).
5. **التحكم باللمس:** الضغط على أزرار (+ / − / إعادة توسيط / تبديل الوضع) يرسل إحداثيات اللمس
   للهاتف عبر نفس وصلة البلوتوث.

## 👀 اللي هتشوفه على شاشة السيارة لما تشتغل

- **خريطة حقيقية بشوارعها** مجمعة من المربعات ومحفوظة محلياً في الكاش.
- **عداد سرعة كبير** في المنتصف بالأرقام («NN km / h»).
- **سهم المنعطف القادم** (يمين/يسار/دوران/وجهة...) أعلى اليسار، تحته **المسافة للّفة** و**اسم الشارع**.
- **خط المسار (Cyan)** مرسوم فوق الخريطة، مع **علامة السيارة** عند منتصف الشاشة.
- **المسافة المتبقية (REMAINING)** و**مدة الوصول المتوقعة (EST. DURATION / ETA)**.
- **أزرار لمس**: تكبير/تصغير/إعادة توسيط/تبديل الوضع.
- **حالة الاتصال**: «BT PAIRED & SYNCED» عند الاقتران.

## 🗺️ خريطة الموبايل وخريطة الشاشة: من أين تأتي البيانات؟

- **الموبايل:** يعتمد على **OpenStreetMap (OSM)** المفتوحة والمجانية عالمياً (ولا يعتمد على Google Maps لأن شروط استخدام جوجل تمنع استخراج وتخزين مربعات الخرائط للأجهزة الخارجية).
- **التخزين الذكي:** الهاتف يقوم بتنزيل المربعات المحيطة بموقعك ومسار الرحلة، ويعرضها مباشرة في واجهة التطبيق، ويبثها للشاشة عبر البلوتوث لتحفظها الشاشة على الـ SD Card.
- **إقرار الاستلام (ACK):** بمجرد أن تؤكد الشاشة استلام المربع، يضع الهاتف المربع في قائمة المربعات المكتملة لديه ولا يبثه مجدداً.

## 🚗 تشغيل تطبيق الشاشة (Car App)

**الأسهل:** نزّل `CheryNav.exe` جاهزاً من رابط التحميل أعلى الصفحة، وانسخه لشاشة السيارة
(مثلاً `\ResidentFlash\` أو `\Storage Card\`) وشغّله.

### بناؤه بنفسك
- **على لينكس / الـ CI (cegcc):** التولشين يُثبّت بـ `tools/setup-toolchain.sh`، ثم:
  ```bash
  make -C car_app CEGCC=/opt/mingw32ce
  ```
  ينتج `car_app/build/CheryNav.exe` بعد تمريره على `tools/pe_fixup.py` و`pe_check.py`
  (للتأكد إنه يعتمد على `coredll` فقط ويُحمّل على الجهاز). والـ GitHub Actions بيعمل ده تلقائياً
  وبينشر الملف في الـ release.
- **على ويندوز (بديل):** افتح `car_app/CheryNav.sln` في Visual Studio 2008، اختر المنصة
  `Windows Mobile 5.0 Pocket PC SDK (ARMV4I)` والوضع `Release`، واضغط Build.

## 📱 تشغيل تطبيق الموبايل (Android)

1. نزّل `app-debug.apk` من رابط التحميل أعلاه وثبّته، أو افتح `mobile_app/` في Android Studio واضغط Run.
2. فعّل **البلوتوث** واقرن الهاتف بموديول بلوتوث السيارة.
3. افتح **CheryNav** وفعّل سويتش **Bridge Service** (يعمل كخدمة في الخلفية).
4. شغّل `CheryNav.exe` على الشاشة — هيتصل عبر البلوتوث ويبدأ عرض التوجيه والسرعة والمسار.

> يوجد وضع محاكاة مدمج (رحلة تجريبية) لاختبار الرسم بدون تحرّك السيارة.

## 🧪 المحاكاة على الكمبيوتر (Simulator)

لاختبار البروتوكول وتدفّق البيانات بدون شاشة أو موبايل:

```bash
python3 simulator/test_phone_server.py            # محاكي الهاتف
python3 simulator/test_car_client.py 127.0.0.1    # محاكي الشاشة (نافذة أخرى)
```

> المحاكيات تستخدم TCP على جهازك للراحة؛ أما المنتج الفعلي فبلوتوث فقط.
